# Food Delivery Analysis SQL Project

## Project Overview

This project I undertook uses SQL and SQLite to analyse food-delivery operations data across customers, restaurants, menu items, orders, and order items. I also created an interactive Power BI dashboard to present the insights from this analysis.

The purpose of the project is to practise core SQL skills relevant to a data-focussed role, while answering practical business questions about restaurant performance, customer ordering behaviour, revenue, product popularity and monthly trends.

The aim was to practise core SQL skills used in data-focussed roles, including:
- Filtering and sorting data
- Aggregate functions
- `GROUP BY`
- `JOIN`s
- `CASE` statements
- Common Table Expressions (CTEs)
- Customer segmentation
- Revenue and trend analysis
---

The findings and recommendations are intended to support decisions relating to restaurant partnerships, marketing, customer retention and promotions/offers.

The interactive dashboard was built in Power BI and allows users to filter performance by month, city and cuisine.

The dashboard contains:
- KPI cards for total revenue, total orders and average order value
- Monthly revenue trend analysis
- Revenue by city and cuisine
- Restaurant revenue compared with customer rating
- Top 10 restaurants by revenue
- Customer segmentation overview
- Top 10 menu items - volume versus revenue analysis
- Dropdown slicers for month, city and cuisine
