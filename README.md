# FoodDeliverySQLProject
A project I undertook on a food delivery dataset to analyse operations using SQL in SQLite

The aim was to practise core SQL skills used in data-focussed roles, including:
- Filtering and sorting data
- Aggregate functions
- `GROUP BY`
- `JOIN`s
- `CASE` statements
- Common Table Expressions (CTEs)
- Customer segmentation
- Revenue and trend analysis

The project uses a food delivery dataset containing customers, restaurants, menu items, orders and order-item data.
